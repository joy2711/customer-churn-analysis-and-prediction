# customer-churn-analysis-and-prediction
This project analyzes customer churn behavior using Power BI to identify key churn drivers, uncover customer retention patterns, and generate predictive business insights.

The dashboard includes:

Data Cleaning & Transformation using Power Query
Customer Churn Rate Analysis
Demographic Churn Insights
Contract & Payment Method Impact Analysis
Tenure Distribution Trends
Internet Service Churn Comparison
Interactive KPI Dashboard
Predictive Insights for Customer Retention Strategies
Tools Used
Microsoft Power BI
Power Query
Data Modeling
DAX Measures
Data Visualization
Key Insights

The analysis highlights how factors such as contract type, payment methods, tenure length, and internet service subscriptions influence customer churn, helping businesses make data-driven retention decisions.

Business Value

This dashboard enables decision-makers to:

Identify high-risk churn customers
Improve retention strategies
Optimize service offerings
Increase long-term customer lifetime value
